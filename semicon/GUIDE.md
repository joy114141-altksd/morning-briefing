# 반도체 주간 브리핑 선별 기준

매주 월요일 아침(06:45 KST 시작, 7시 전후 도착) 예약 작업(Claude)이 이 문서를 읽고 지난주 뉴스를 골라
`semicon/news/YYYY-MM-DD.json`(보내는 월요일 날짜)으로 저장합니다.
이 파일이 main에 푸시되면 GitHub Actions(`semicon-news.yml`)가 텔레그램으로 보냅니다.
**기준을 바꾸고 싶으면 이 문서만 고치면 됩니다** (다음 회차부터 반영).

## 누가, 왜 읽나

반도체 소자 연구실에 석·박사로 진학할 사람이 **업계 흐름과 업계에서 쓰는 기본 용어에 익숙해지려고** 읽습니다.
요약을 읽다가 모르는 건 본인이 직접 찾아봅니다. 그래서:

- **뉴스 요약만** 씁니다. 해석·전망·의미 풀이·질문·용어 설명은 넣지 않습니다.
- 업계 기사가 실제로 쓰는 용어를 **쉽게 풀지 말고 그대로** 씁니다. 대신 바로 검색할 수 있게 **영문 원어나 약어를 함께** 적습니다. 예: 후면전력공급(BSPDN), 고대역폭메모리(HBM), 게이트올어라운드(GAA)
- 주 1회라서 **주요 뉴스는 빠짐없이** 넣습니다. 양이 적으면 의미가 없습니다. 보통 한 주 10~20개, 많은 주는 더 넣어도 됩니다 (최대 25개).
- 대신 **안 중요한 것은 넣지 않습니다** (아래 "빼는 것").

## 기간

보내는 월요일 기준 **지난주 월요일 00:00 ~ 일요일 24:00 (KST)**.
직전 주간 브리핑(`semicon/news/`의 이전 파일)에 이미 나온 뉴스는 빼고, 큰 후속(공식 확정, 수치 공개)만 넣습니다.

## 분야 (넓은 → 좁은 순서)

| key | 분야 | 들어가는 것 |
|---|---|---|
| `flow` | 🌐 큰 흐름 | 업황(메모리 가격 동향, AI 수요, 시장 전망 공식 발표), 주요 기업 실적·가이던스·대규모 투자(CAPEX)·M&A·합작, 국가 단위 정책(수출규제, 관세, 보조금, 반도체법), 주요 기업의 전략 변화 |
| `memory` | 💾 메모리 | D램·HBM·낸드·신메모리의 양산, 고객사 공급·인증, 세대 전환, 공식 로드맵, 증설, 가격 |
| `logic` | ⚙️ 로직·파운드리 | 파운드리 공정 양산·로드맵, 고객 수주, 팹 증설, 신구조(GAA·BSPDN·CFET 등), 노광(EUV·High-NA) 도입, 주요 칩(GPU·AI 가속기·CPU·모바일 AP) 발표·출시 |
| `packaging` | 📦 패키징 | 2.5D/3D 집적(CoWoS·SoIC 등), 하이브리드 본딩, 유리 기판, 패널 레벨 패키징, CPO, 칩렛·UCIe, 후공정(OSAT) 증설·수주 |

- 한 뉴스는 가장 잘 맞는 분야 하나에만 넣습니다.
- 그 주에 해당 분야 뉴스가 없으면 그 분야는 빼도 됩니다.
- **뉴스가 하나도 없는 주는 파일을 만들지 않고 보내지 않습니다.**

## 빼는 것 (안 중요한 것)

- 중소 업체 단독 소식, 장비·소재 신제품 출시 단독(주요 업체의 핵심 장비 제외)
- 인사·조직개편, 전시회 부스·수상·MOU(금액·물량 없는 것), 사회공헌
- 주가 등락·시황 기사, "수혜주", 목표주가
- 루머·추측("~할 듯", "~설", 익명 소식통 단독), 칼럼·사설·인터뷰 전망
- 유튜브·블로그·커뮤니티·X 출처, 출처 불명 번역 기사

## 쓰는 법 (전부 직접 쓴 한국어, 기사 문장 옮기지 않기)

| 필드 | 내용 |
|---|---|
| `headline` | 무슨 일인지 한 줄 |
| `summary` | 사실 요약 2~3문장. 누가·무엇을·언제·숫자(금액·공정·시점). 용어는 그대로, 영문 원어·약어 병기. 해석·전망 금지 |
| `basis` | `공식`(회사·정부·학회 발표) 또는 `보도`(주요 매체 확인 보도) |
| `source`, `url` | 가장 1차에 가까운 원문 1개 |
| `paper` | 학회 논문·세션 정보 링크 (있을 때만, 선택) |

- 파일 맨 위 `oneliner`: 지난주 전체를 꿰는 한 줄 요약.
- 수치는 원문에서 확인된 것만 씁니다.

## 파일 형식 (`semicon/news/YYYY-MM-DD.json`, 날짜는 보내는 월요일)

```json
{
  "date": "2026-11-30",
  "oneliner": "지난주를 꿰는 한 줄",
  "sections": [
    {
      "key": "memory",
      "items": [
        {
          "headline": "짧은 제목",
          "summary": "사실 요약 2~3문장",
          "basis": "공식",
          "source": "키오시아",
          "url": "https://...",
          "paper": "https://..."
        }
      ]
    }
  ]
}
```

- `key`는 `flow` / `memory` / `logic` / `packaging`. 빈 분야는 넣지 않아도 됩니다.
- 저장 전에 `python semicon/send_news.py semicon/news/YYYY-MM-DD.json --dry-run`으로 형식 확인
