# 반도체 뉴스 선별 기준

매일 아침 예약 작업(Claude)이 이 문서를 읽고 뉴스를 골라 `semicon/news/YYYY-MM-DD.json`으로 저장합니다.
이 파일이 main에 푸시되면 GitHub Actions(`semicon-news.yml`)가 텔레그램으로 보냅니다.
**기준을 바꾸고 싶으면 이 문서만 고치면 됩니다** (다음 날부터 반영).

## 관점

증권가 애널리스트가 아침 회의 전에 챙겨 보는 수준의 **큰 흐름**.
전공 지식(물성·공정 디테일)보다 "이게 업황·실적·주가·산업 구도에 어떤 영향을 주나"가 중심.

## 범위 (기준 시점: 직전 브리핑 이후 ~ 지금, 보통 최근 24시간. 월요일·연휴 다음 날은 주말 포함)

## 분야 (위에서 아래로 넓은 → 좁은 순서)

| 순서 | 분야 | 들어가는 것 | 개수 |
|---|---|---|---|
| 1 | 🌐 반도체 전반 | 실적·가이던스, 업황(메모리 가격, 수요), 대형 투자·CAPEX, M&A, 정책(수출규제·관세·보조금), 빅테크 AI 투자 중 반도체 수요에 직결되는 것 | 2~5 |
| 2 | 🔬 반도체 소자 | 메모리(DRAM·HBM·NAND), 로직·파운드리 공정(2nm·GAA·BSPDN), 차세대 소자(CFET 등)의 **양산·고객 인증·수율·로드맵 공식 발표** | 1~4 |
| 3 | 🏭 장비·소재·패키징 | 노광·식각·증착 장비, 소재, 첨단 패키징(CoWoS·하이브리드 본딩·HBM 적층), 기판 | 0~3 |

- 한 뉴스는 가장 잘 맞는 분야 하나에만 넣습니다.
- 해당 분야에 기준을 넘는 뉴스가 없으면 그 분야는 통째로 뺍니다 (억지로 채우지 않기).
- 전체 합계 최대 10개. 정말 중요한 게 없는 날은 1~2개만 보내도 됩니다.

## 믿을 만한 출처 (우선순위 순)

1. **1차 출처**: 회사 공식 발표·IR·실적 자료, 공시(DART·SEC 8-K/10-Q), 정부·규제기관 발표(산업부, 미 상무부 BIS, 중국 상무부 등), 업계 단체(SIA·WSTS·SEMI)
2. **주요 통신·경제지**: Reuters, Bloomberg, Nikkei Asia, WSJ, FT, CNBC, 연합뉴스, 한국경제, 매일경제, 서울경제, 조선비즈
3. **반도체 전문 매체·리서치**: 전자신문, 디일렉(THE ELEC), ZDNet Korea, TrendForce, DigiTimes(단, DigiTimes 단독은 2번 출처로 확인될 때만), Tom's Hardware·AnandTech류는 기술 확인용
4. **증권사 리포트**: 내용 자체보다 "주요 증권사가 업황 전망·목표가를 크게 바꿨다"는 사실이 뉴스일 때

## 빼는 것

- 루머·추측: "~할 듯", "~설", "가능성", "검토 중", 익명 소식통 **단독** (Reuters·Bloomberg 단독이라도 회사가 부인했으면 제외, 부인 없이 2곳 이상이 확인하면 포함 가능하되 `basis`를 `보도`로)
- 주가 등락만 다룬 시황 기사, 테마주·급등주 기사, "수혜주 ○선"
- 홍보성 기사(전시회 부스, 수상, MOU 중 금액·물량 없는 것), 칼럼·사설·인터뷰 전망
- 유튜브·블로그·커뮤니티·X(트위터) 출처, 출처 불명 번역 기사
- 직전 3일 브리핑(`semicon/news/`의 이전 파일)에 이미 나온 뉴스. 단, 큰 후속(공식 확정, 숫자 공개)이 있으면 "후속"으로 포함

## 파급력 판단 (하나 이상 해당해야 포함)

- 상위 기업(삼성전자·SK하이닉스·TSMC·인텔·마이크론·엔비디아·AMD·브로드컴·ASML·AMAT·램리서치·TEL·키옥시아·SMIC·CXMT 등)의 실적·가이던스·대규모 투자·고객 확보
- 메모리·파운드리 **가격** 변화 (고정거래가, 계약가, 웨이퍼 가격)
- 국가 단위 정책 변화 (수출규제, 관세, 보조금, 반도체법)
- 산업 구도를 바꾸는 계약·M&A·합작 (금액이나 물량이 공개된 것)
- 기술 경쟁 판도 변화가 **공식 확인**된 것 (양산 개시, 고객 인증 통과, 수율 공식 언급)

## 쓰는 법

- 제목·요약·의미 모두 **직접 쓴 한국어**로 (기사 문장을 그대로 옮기지 않기, 인용은 꼭 필요할 때 15단어 미만 1개까지)
- `summary`: 사실만 1~2문장. 숫자(금액·%·시점)가 있으면 넣기
- `why`: 증권가 시각에서 의미 한 줄 (누구에게 호재/악재인지, 업황 신호인지). 확정되지 않은 전망은 "~ 가능성" 대신 근거와 함께 짧게
- `basis`: `공식`(회사·정부·공시 발표) 또는 `보도`(주요 매체 확인 보도)
- `url`: 가장 1차에 가까운 출처 링크 1개 (공식 발표가 있으면 그것)

## 파일 형식 (`semicon/news/YYYY-MM-DD.json`)

```json
{
  "date": "2026-11-28",
  "sections": [
    {
      "key": "general",
      "items": [
        {
          "headline": "짧은 제목",
          "summary": "사실 1~2문장",
          "why": "의미 한 줄",
          "basis": "공식",
          "source": "Reuters",
          "url": "https://..."
        }
      ]
    },
    { "key": "device", "items": [] },
    { "key": "equipment", "items": [] }
  ],
  "note": ""
}
```

- `key`: `general`(반도체 전반) / `device`(소자) / `equipment`(장비·소재·패키징)
- 중요한 뉴스가 하나도 없는 날: `sections`를 모두 비우고 `note`에 "오늘은 크게 볼 뉴스가 없어요" 같은 한 줄
- 저장 전에 `python semicon/send_news.py semicon/news/YYYY-MM-DD.json --dry-run`으로 형식 확인
