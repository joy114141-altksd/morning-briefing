# 반도체 뉴스 선별 기준

매일 아침 예약 작업(Claude)이 이 문서를 읽고 뉴스를 골라 `semicon/news/YYYY-MM-DD.json`으로 저장합니다.
이 파일이 main에 푸시되면 GitHub Actions(`semicon-news.yml`)가 텔레그램으로 보냅니다.
**기준을 바꾸고 싶으면 이 문서만 고치면 됩니다** (다음 날부터 반영).

## 누가, 왜 읽나

반도체 **소자 연구실에 석·박사로 진학할 사람**이 업계를 보는 **소양과 눈**을 기르려고 읽습니다.
투자자용 브리핑이 아닙니다. 그래서:

- 고르는 기준: "업계 사람들이 이번 주 내내 이야기할 만한가?" 세부 수치보다 **판이 어떻게 움직이는지**.
- 쓰는 기준: 뉴스 하나마다 **업계에서 왜 중요한지** + **소자 연구와 어떻게 이어지는지**를 짚어 줍니다.
- 양: 하루 **0~3개**. 적을수록 좋습니다. 3개를 넘기지 않습니다.

## 분야 (넓은 → 좁은 순서)

| key | 분야 | 들어가는 것 |
|---|---|---|
| `flow` | 🌐 큰 흐름 | 업황의 방향(메모리 호황·불황, AI 수요), 산업 구도를 바꾸는 사건(대형 M&A·합작, 주요 기업의 전략 전환, 국가 단위 규제·지원책), 주요 기업 실적 중 **업계 전망을 바꾸는 것** |
| `tech` | 🔬 기술·소자 | 주요 기업의 신공정·신구조 **양산이나 공식 로드맵**(GAA, 후면전력공급 BSPDN, CFET, 4F²·3D D램, 차세대 NAND, HBM 세대 전환, 하이브리드 본딩, 첨단 패키징), IEDM·VLSI·ISSCC 등 학회에서 **주요 기업**이 낸 발표, 새로운 메모리·소자가 실제 시스템에 들어가는 첫 사례 |

- 한 뉴스는 더 잘 맞는 분야 하나에만 넣습니다.
- 해당 분야에 기준을 넘는 뉴스가 없으면 그 분야는 통째로 뺍니다.

## 빼는 것

- **너무 세부적인 것**: 관세율·주가 등락률·목표주가, 장비·제품 스펙 나열, 가격 전망의 소수점 차이
- **덜 중요한 것**: 중소 업체 소식, 장비·소재 신제품 출시 단독(산업 구도를 바꾸는 경우만 예외), 인사·조직개편, 전시회·수상·MOU
- 루머·추측("~할 듯", "~설", 익명 소식통 단독), 시황 기사, 칼럼·사설
- 유튜브·블로그·커뮤니티·X 출처, 출처 불명 번역 기사
- 직전 3일 브리핑(`semicon/news/`의 이전 파일)에 이미 나온 뉴스. 큰 후속(공식 확정)만 예외

## 믿을 만한 출처

1. 회사 공식 발표·IR·공시, 정부 발표, 학회 공식 프로그램(IEDM·VLSI·ISSCC)
2. Reuters, Bloomberg, Nikkei, WSJ, FT, 연합뉴스, 한국경제, 매일경제, 전자신문, 디일렉
3. 기술 확인용: IEEE Spectrum, EE Times, SemiEngineering, TrendForce

## 쓰는 법 (전부 직접 쓴 쉬운 한국어, 기사 문장 옮기지 않기)

| 필드 | 내용 | 길이 |
|---|---|---|
| `headline` | 무슨 일인지 한눈에 | 한 줄 |
| `summary` | 무슨 일이 있었나. 꼭 필요한 숫자만 | 1~2문장 |
| `why` | 업계에서 왜 중요한가 (큰 그림) | 1문장 |
| `device` | 🔬 소자 연구자 눈으로 보면: 어떤 소자·공정·구조 이야기와 이어지는지, 무엇이 기술적 병목인지 | 1문장 |
| `term` | 📘 처음 보면 헷갈릴 핵심 용어 하나 풀이 (선택) | 한 줄 |
| `basis` | `공식`(회사·정부·학회 발표) 또는 `보도`(주요 매체 확인 보도) | |
| `source`, `url` | 가장 1차에 가까운 출처 1개 | |

- 전문용어는 처음 나올 때 괄호로 짧게 풀어 줍니다.
- 투자 조언처럼 쓰지 않습니다 (호재·악재, 매수 같은 표현 금지).

## 파일 형식 (`semicon/news/YYYY-MM-DD.json`)

```json
{
  "date": "2026-11-28",
  "sections": [
    {
      "key": "flow",
      "items": [
        {
          "headline": "짧은 제목",
          "summary": "무슨 일",
          "why": "업계에서 왜 중요한지",
          "device": "소자 관점 한 문장",
          "term": "용어: 한 줄 풀이",
          "basis": "공식",
          "source": "TrendForce",
          "url": "https://..."
        }
      ]
    },
    { "key": "tech", "items": [] }
  ],
  "note": ""
}
```

- 중요한 뉴스가 없는 날: `sections`를 모두 비우고 `note`에 "오늘은 크게 볼 뉴스가 없어요" 한 줄
- 저장 전에 `python semicon/send_news.py semicon/news/YYYY-MM-DD.json --dry-run`으로 형식 확인
