# 반도체 주간 브리핑 선별 기준

매주 월요일 아침(06:45 KST 시작, 7시 전후 도착) 예약 작업(Claude)이 이 문서를 읽고 지난주 뉴스를 골라
`semicon/news/YYYY-MM-DD.json`(보내는 월요일 날짜)으로 저장합니다.
이 파일이 main에 푸시되면 GitHub Actions(`semicon-news.yml`)가 텔레그램으로 보냅니다.
**기준을 바꾸고 싶으면 이 문서만 고치면 됩니다** (다음 회차부터 반영).

## 누가, 왜 읽나

반도체 **소자 연구실에 석·박사로 진학할 사람**이 업계를 보는 **소양과 눈**을 기르려고 읽습니다.
투자자용 브리핑이 아닙니다.

- 고르는 기준: "업계 사람들이 지난주 내내 이야기했거나, 1년 뒤에도 기억될 만한가?" 세부 수치보다 **판이 어떻게 움직이는지**.
- 해석 수준: **대학원 수준**. 메커니즘·병목·트레이드오프까지 짚되, 문장은 간결하게.

## 기간

보내는 월요일 기준 **지난주 월요일 00:00 ~ 일요일 24:00 (KST)**.
직전 주간 브리핑(`semicon/news/`의 이전 파일)에 이미 나온 뉴스는 빼고, 큰 후속(공식 확정, 수치 공개)만 "후속"으로 넣습니다.

## 분야 (넓은 → 좁은 순서)

| key | 분야 | 들어가는 것 |
|---|---|---|
| `flow` | 🌐 큰 흐름 | 업황의 방향(메모리 사이클, AI 수요), 산업 구도를 바꾸는 사건(대형 M&A·합작, 주요 기업 전략 전환, 국가 단위 규제·지원책), 업계 전망을 바꾸는 주요 기업 실적 |
| `memory` | 💾 메모리 | D램(1c·1d nm, 4F², 3D D램, IGZO 등 신채널), HBM 세대 전환(HBM4·4E, 베이스 다이 로직 공정화), NAND(적층 수, CBA·웨이퍼 본딩, QLC), 신메모리(MRAM·ReRAM·FeRAM·SCM)의 양산·고객 채택·공식 로드맵 |
| `logic` | ⚙️ 로직·파운드리 | 2nm 이하 공정 양산·수율 공식 언급, GAA(나노시트·포크시트), 후면전력공급(BSPDN), CFET, High-NA EUV 도입, 2D 채널 등 신소재, 주요 고객 수주 |
| `packaging` | 📦 패키징 | CoWoS·SoIC 등 2.5D/3D 집적, 하이브리드 본딩, 유리 기판, 패널 레벨 패키징, CPO(광 패키징), 칩렛·UCIe |

- 분야마다 **0~3개**, 한 주 **최대 8개**. 기준을 넘는 게 없는 분야는 통째로 뺍니다.
- 한 뉴스는 가장 잘 맞는 분야 하나에만 넣습니다.
- **기준을 넘는 뉴스가 하나도 없는 주는 파일을 만들지 않고 보내지 않습니다.**

## 꼭 챙길 것

- **학회**: IEDM(12월), ISSCC(2월), VLSI Symposium(6월), ECTC(5~6월), Hot Chips(8월), Flash Memory Summit(8월). 주요 기업(삼성·SK하이닉스·마이크론·TSMC·인텔·imec·키오시아·CXMT 등) 발표는 기술 흐름의 1차 자료라 우선 포함. 프로그램 공개(채택 논문 발표)도 뉴스.
- 주요 기업 실적 발표의 **기술 언급**(공정 전환 일정, 수율, 세대 전환 비중)

## 빼는 것

- **너무 세부적인 것**: 관세율·주가 등락률·목표주가, 제품 스펙 나열
- **덜 중요한 것**: 중소 업체 소식, 장비·소재 신제품 출시 단독(산업 구도를 바꾸는 경우만 예외), 인사·조직개편, 전시회·수상·MOU
- 루머·추측("~할 듯", "~설", 익명 소식통 단독), 시황 기사, 칼럼·사설
- 유튜브·블로그·커뮤니티·X 출처, 출처 불명 번역 기사

## 믿을 만한 출처

1. 회사 공식 발표·IR·실적 자료·공시, 정부 발표, 학회 공식 프로그램·논문
2. Reuters, Bloomberg, Nikkei, WSJ, FT, 연합뉴스, 한국경제, 매일경제, 전자신문, 디일렉
3. 기술 확인용: IEEE Spectrum, EE Times, SemiEngineering, TrendForce, imec 발표

## 쓰는 법 (전부 직접 쓴 한국어, 기사 문장 옮기지 않기)

| 필드 | 내용 | 길이 |
|---|---|---|
| `headline` | 무슨 일인지 한눈에 | 한 줄 |
| `summary` | 무슨 일이 있었나. 꼭 필요한 숫자만 | 1~2문장 |
| `why` | 업계 의미: 판이 어떻게 움직이는지 | 1문장 |
| `device` | 🔬 소자 깊이: 물리·공정 메커니즘, 병목, 트레이드오프. 확인된 수치가 있으면 포함 (예: 왜 GAA가 누설을 줄이는지, 하이브리드 본딩의 피치·평탄도 문제) | 2~3문장 |
| `open` | 🧪 남은 숙제: 기술적으로 아직 안 풀린 문제 (연구 주제를 보는 눈) | 1문장 |
| `term` | 📘 핵심 용어 하나 풀이 (선택) | 한 줄 |
| `basis` | `공식`(회사·정부·학회 발표) 또는 `보도`(주요 매체 확인 보도) | |
| `source`, `url` | 가장 1차에 가까운 출처 1개 | |
| `paper` | 학회 논문·세션 정보 링크 (있을 때만, 선택) | |

- 파일 맨 위 `oneliner`: 지난주 전체를 꿰는 한 줄 요약.
- 소자 해석은 확실한 물리·공정 사실에 근거하고, 추측이면 추측이라고 씁니다. 수치는 출처에서 확인된 것만.
- 투자 조언처럼 쓰지 않습니다 (호재·악재, 매수 같은 표현 금지).

## 파일 형식 (`semicon/news/YYYY-MM-DD.json`, 날짜는 보내는 월요일)

```json
{
  "date": "2026-11-30",
  "oneliner": "지난주를 꿰는 한 줄",
  "sections": [
    {
      "key": "memory",
      "items": [
        {
          "headline": "짧은 제목",
          "summary": "무슨 일",
          "why": "업계 의미",
          "device": "소자 깊이 2~3문장",
          "open": "남은 숙제 한 문장",
          "term": "용어: 한 줄 풀이",
          "basis": "공식",
          "source": "SK하이닉스",
          "url": "https://...",
          "paper": "https://..."
        }
      ]
    }
  ]
}
```

- `key`는 `flow` / `memory` / `logic` / `packaging`. 빈 분야는 넣지 않아도 됩니다.
- 저장 전에 `python semicon/send_news.py semicon/news/YYYY-MM-DD.json --dry-run`으로 형식 확인
